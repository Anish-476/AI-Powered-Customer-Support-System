AI-Powered Customer Support Ticketing System

Project Overview

This project is built using Salesforce to improve customer support operations through automation and AI-generated suggested responses.

Technologies Used

- Salesforce CRM
- Agentforce
- Prompt Builder
- Salesforce Flow
- Salesforce DX
- Visual Studio Code

Key Features

- AI-powered customer support agent
- Case-based suggested responses
- Prompt Template integration
- Automated support assistance

Agent Configuration

- Agent Name: AI Customer Support Agent
- Subagent: CST Topic
- Prompt Template: AI Suggested Response

Testing

The agent was tested using Salesforce Agent Preview with an existing Case record.
